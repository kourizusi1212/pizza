# 🍕 Pizzeria Online（一人称）

注文を受けて、自分の手でピザを作って渡す。協力プレイ対応のオンライン3Dピザ屋（Node.js + WebSocket + three.js）。PC向け（マウスとキーボード）。

## 操作
`WASD` 移動 / マウス 視点（画面クリックで開始）/ `E` 操作 / 左クリック 作業 / `Q` トッピング取り消し / `K` クイックセーブ / `Esc` 一時停止

## ピザ作りの手順（注文票に進行状況が出ます）
1. カウンターのお客さんを見て `E` で注文を受ける（吹き出しにトッピングと数）
2. ① 左の木箱で `E` → 生地をとる
3. ② 作業台で 左クリック長押し → めん棒でのばす
4. ③ 左クリック長押し → おたまでソース
5. ④ 左クリック長押し → チーズ
6. ⑤ ボウルで `E` でつまみ、作業台で 左クリック → 注文どおりの数だけのせる（違ったら `Q`）
7. 作業台で `E` → ピールにのせ、空いたオーブンで `E`
8. ⑦ 焼き上がりバーの緑ゾーンで、そのオーブンに `E` → 取り出す（早いと生焼け、遅いと焦げ）
9. ⑧ カット台で `E` → 左クリック×3でカット → `E` で箱づめ
10. ⑩ 注文したお客さんに `E` で渡す。出来と待たせた時間で報酬が変わります

手順は順番どおりにしか進みません。やり直しはゴミ箱（左奥）で `E`。他のプレイヤーは別の注文を受けて同時に作れます（オーブンは共有）。

## セーブ / ロード
- `K` またはメニューの 💾 → ブラウザに保存、⬇ → JSONファイル書き出し
- 📂 / 📁 ロード: ゲーム中はホストのみ。ロビーでは「ルームを作る」前に読み込むと、そのデータで開始
- セーブはプレイヤー側に保存されるので、Render無料プランのサーバー再起動でも消えません（`Esc`でカーソルを出してボタン操作）

## ローカル起動
```
npm install
npm start      # http://localhost:3000
```

## Render
1. **New + → Web Service**（`render.yaml` があるので **Blueprint** でも可）→ このリポジトリを選択
2. Build: `npm install` / Start: `npm start`
3. 発行されたURLを開けばOK（WebSocketは同じドメインで動きます）。無料プランは無操作で休止し、復帰に1分ほどかかります
